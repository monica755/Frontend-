Block Level Element:

Block-level elements in HTML are elements that always start on a new line and automatically take up the full available horizontal width of their parent container

Types of Element:

  • form
  • aside
  • Main
  • Nav
  • header

DT:

dt :tag defines a description list

Characteristics of Block-level Elements:

  • Always start on a new line.
  • Take up the full width available.
  • Width and height can be controlled via CSS.
  • Can contain other block-level as well as inline elements.
