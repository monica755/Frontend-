# IT : 2030 VISION — Extinction or Evolution?

A modern, professional, responsive website built with **HTML5**, **Bootstrap 5.3.3**, and **Vanilla JavaScript** answering the pivotal question:
> *"In 2030, will there be an IT industry or what will it be?"*

---

## 🌟 Key Features

1. **Clear & Impactful Content Strategy**:
   - Direct, hype-free answers to whether traditional IT will disappear or evolve.
   - **Myth vs. Reality**: 3 side-by-side analysis cards debunking common tech career fears.
   - **The Evolution Matrix (2010 vs 2024 vs 2030)**: Interactive tabs exploring Software Engineering, QA & Testing, Cloud & DevOps, Cybersecurity, and IT Support.
   - **Four Plausible 2030 Scenarios**:
     - The Disposable Software Era
     - The Physical & Bio-Compute Frontier
     - The Verification & Liability Crisis
     - The Rise of the 1-Person Tech Giant
   - **Actionable 4-Pillar Survival Toolkit** for students, developers, and engineers.

2. **Interactive JavaScript Components**:
   - **Dark / Light Theme Toggler** with `localStorage` memory.
   - **Interactive 2030 Career Readiness Quiz**: 4-question interactive assessment that computes a score and provides tailored recommendations.
   - **2030 Role Radar**: Live category filters (`All`, `High Demand / Sunrise`, `Deeply Transformed`, `Automated / Sunset`) plus instant live search.
   - **Smooth Scroll & Back-to-Top** floating button.

3. **Design & UX**:
   - Bootstrap 5.3.3 grid and components with custom CSS design tokens.
   - Clean typography using the Google **Inter** font family.
   - Responsive across mobile phones, tablets, laptops, and 4K displays.
